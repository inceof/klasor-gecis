# Installer language files

ChineseSimplified.isl and Hindi.islu are the translator-authored language files
from the Inno Setup 6.7.3 source distribution:

https://github.com/jrsoftware/issrc/tree/is-6_7_3/Files/Languages/Unofficial

Original translator credits and notices are retained in each file. Hindi's
obsolete keys were removed and 6.7.3 message additions translated by inceof
in 2026, keeping all format placeholders. These are
third-party installer translations, separate from the application's MIT code.
The upstream Inno Setup license is retained as LICENSE-InnoSetup.txt.
English, Turkish, Spanish and Arabic use the files installed with Inno Setup 6.
